## 🛠️ Tecnologias Utilizadas

Este projeto foi desenvolvido utilizando as melhores práticas de mercado para garantir velocidade, acessibilidade e um design limpo:

* **HTML5 Semântico** — Estrutura organizada e otimizada para SEO.
* **CSS3 / Estilos Modernos** — Uso de variáveis CSS, Flexbox, Grid Layout e efeitos de *Glassmorphism*.
* **JavaScript (ES6+)** — Interatividade fluida, manipulação de DOM e controle de menu mobile.
* **Responsividade** — Layout adaptável para dispositivos móveis, tablets e desktops (Mobile-First).

---

## ✨ Funcionalidades Principais

* **Menu Sticky com Efeito de Vidro Fosco (`Backdrop Filter`)** — Navegação sempre acessível com transições suaves.
* **Seção de Projetos em Destaque** — Vitrine para os principais trabalhos realizados, com links diretos para repositórios.
* **Apresentação de Serviços e Trajetória** — Seções detalhadas sobre consultoria web, desenvolvimento e cronograma de trabalho.
* **Botão Flutuante do WhatsApp** — Facilita o contato rápido e direto de potenciais clientes.
* **Menu Mobile Responsivo** — Navegação otimizada para telas menores com menu interativo.
